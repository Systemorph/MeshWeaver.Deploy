memex-local is installed. Open a new terminal window (the PATH change takes effect in new shells) and run:

memex-local doctor      # which copy of each tool is in use, from where, and whether it met the floor
memex-local registry https://<your plugin registry>
az login                # the registry mode pulls the portal image with the Docker CLI + Azure CLI (not in this package)
memex-local up          # Colima → image → chart → Ollama → port-forward; idempotent

Still needed from elsewhere: Ollama, the Docker CLI and the Azure CLI — doctor reports each; MEMEX_OLLAMA_MODEL=none skips only the large model, not Ollama.

The toolchain probe's result is in /opt/memex/etc/tools.report. Re-running this installer repairs only what is missing and changes nothing else.

Offer this Mac to the fleet: memex-local backlease enroll --control https://<control> --deployment <id> (a managed preference pre-fills both on a fleet-managed Mac).
